# Design Radar 网站完整路由结构

## 📍 路由地图

```
design-radar.com/
│
├── / ........................... 首页（主导航）
├── /trends ..................... 设计趋势页面
├── /competitors ............... 竞品追踪页面

├── /article/[id] .............. 文章详情页面

├── /tag/[slug] ................ 标签页面
├── /admin ..................... 后台 CMS
└── /archives .................. 历史周刊列表
```
